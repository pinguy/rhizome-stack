# Workspace rules

- Preserve user work and private data.
- Inspect before changing state.
- Back up material files before changing them.
- Treat configuration as unverified until the real request path passes.
- Do not publish, message, purchase or change accounts without explicit scope.
- Store credentials outside version control with mode `0600`.
- Discover available skills in `skills/*/SKILL.md`; load full instructions and
  references only when their trigger matches the current task.
- Use existing notes as hypotheses and check them against current evidence.
- Keep observations, assumptions, decisions and test results distinct.
- Record unfinished work in a short handover with the next action and receipts.
- Challenge a mistaken premise plainly; do not agree merely to be agreeable.
- Installed council and blackboard skills do not themselves authorise delegation
  or sending messages. Follow the user's current task scope.
