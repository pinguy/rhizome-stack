## What transferred well

- Lock the creative premise early and make each motif do more than one job.
- Research becomes useful when it is converted into prompt vocabulary, timing rules, rights decisions, or authentic source artifacts.
- Lock the song before shot timing. Correct beat-grid phase against audible anchors.
- Establish character and world canon before bulk image/video generation.
- Build deterministic engines for exact motion design, text, cursors, windows, or other repeatable geometry.
- Write the complete first-round video prompt book in one context before submission.
- Pilot a few difficult shots before generating volume.
- Separate high-volume atmospheric assets from continuity-critical precision shots.
- Reference-led generation plus mattes/compositing can make generated people usable in designed layouts.
- Validate lyric coverage, scene seams, lip-sync intervals, audio balance, and final duration mechanically where possible.
- Keep provenance, seeds, model identifiers, and immutable accepted outputs.
- Finish with an honest defects list and production lessons.

## Failure lessons

- Long unattended runs fail badly when they hit a permission prompt outside allowed paths.
- Process exits and usage limits require checkpointed, replayable work.
- Image-to-video tools drop small identity and wardrobe details; plan covers and continuity checks.
- Browser automation based on fixed coordinates or prompt-text matching is brittle.
- Generation queues must contain only assets the edit actually needs.
- More concurrency is not automatically faster on constrained hardware.
- A visually attractive still frame can hide frozen, smeared, or divergent motion.
- Moderation/provider rejection is not a reason to silently change the creative or routing contract.
